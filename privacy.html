Политика конфиденциальности yt-hub

Дата обновления: 10 октября 2026.

Что это

yt-hub — личное приложение, которым пользуется только его автор для управления собственными YouTube-каналами.

Какие данные используются

  • Адрес электронной почты Google-аккаунта — для входа в приложение.
  • Данные YouTube-каналов пользователя (название, статистика, список видео, аналитические отчёты) — через YouTube Data API и YouTube Analytics API.
  • OAuth-токены доступа — для обращения к YouTube API от имени пользователя.

Как данные хранятся

Данные хранятся в базе данных приложения на сервере автора. Токены хранятся в зашифрованном виде. Данные не передаются третьим лицам, не продаются и не используются в рекламных целях.

Использование Google API

Использование информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ приложения можно отозвать в любой момент на странице myaccount.google.com/permissions. После отзыва сохранённые токены становятся недействительными.
