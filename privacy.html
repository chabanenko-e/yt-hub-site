yt-hub Privacy Policy

Last updated: October 10, 2026.

What yt-hub is

yt-hub is a personal application used only by its author to manage the author's own YouTube channels.

Data used

  • The Google account email address — to sign in to the application.
  • Data about the user's YouTube channels (title, statistics, list of videos, analytics reports) — through the YouTube Data API and YouTube Analytics API.
  • OAuth access tokens — to call YouTube APIs on the user's behalf.

Storage

Data is stored in the application's database on the author's own server. Tokens are stored encrypted. Data is never shared with third parties, sold, or used for advertising.

Use of Google APIs

yt-hub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens become invalid after revocation.
